## What We Build

Lean Code Box 关注实用、可靠的软件。

我们喜欢能够独立运行的程序、清晰的代码边界，以及不需要一整套基础设施才能部署的产品。  
复杂度应该服务于问题，而不是成为问题本身。

- **Simple to deploy**：尽可能减少运行依赖，下载即可启动。
- **Built to last**：重视兼容性、可维护性和长期演进。
- **Self-hosted first**：数据和运行环境掌握在使用者手中。
- **Community driven**：功能来自真实使用场景，而不是功能清单。

## Featured Project

### [GooseForum](https://github.com/leancodebox/GooseForum)

一个使用 **Go + Vue 3** 构建的现代化论坛系统。

单个可执行文件即可运行，默认使用 SQLite，同时支持 MySQL。内置论坛前台、管理后台、权限系统、通知、私信、主题配置与完整的社区功能。

## Our Direction

```text
clear architecture
    + boring infrastructure
    + thoughtful interaction
    + continuous refinement
    = software people can actually keep using
```

我们不追求把每个项目做成框架。

我们更希望它们开箱即用、容易理解，并且在几年之后依然可以放心维护。
